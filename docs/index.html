BatchLAS

A SYCL-first batched linear algebra library for GPUs: batched eigensolvers, SVD, factorizations and BLAS, with CUDA, ROCm, netlib and oneMKL backends.

View BatchLAS on GitHub

What is BatchLAS?

BatchLAS is a C++20 library for solving many small and medium dense linear algebra problems at once on the GPU. It is written SYCL-first: its own kernels are portable SYCL, and optional vendor backends plug in for CUDA (cuBLAS / cuSOLVER), ROCm, netlib BLAS/LAPACK and oneMKL. The backend is chosen from the device a queue runs on, so the same code targets different hardware.

An optional pybind11-based Python package exposes the library to NumPy dense arrays and SciPy sparse matrices.

Features

  • Batched BLAS: gemm, gemv, symm, syrk, syr2k, trmm, trsm, plus Hermitian hemm, herk, her2k
  • Batched LAPACK-style factorizations: Cholesky (potrf), LU (getrf, getrs, getri), QR (geqrf, orgqr, ormqr)
  • Batched eigensolver and SVD: symmetric syev, partial syevx, and gesvd (one-sided Jacobi)
  • Sparse and spectral: spmm, lanczos, tridiagonal steqr / stedc, ritz_values, iluk preconditioning
  • Orthogonalization and utilities: ortho with several algorithms, matrix generators, norms, condition numbers
  • Python bindings with NumPy/SciPy interop and twelve example notebooks

Performance vs cuSOLVER

BatchLAS's Auto mode routes each call — per routine, matrix size and batch size — between its own kernels and the vendor library, so where cuSOLVER is faster for a shape, that is the path taken. For batches of small matrices, BatchLAS's own kernels often win. Measurements committed in the repository (float, NVIDIA RTX 4090, CUDA backend, large batch):

  • Batched symmetric eigensolver (syev, with eigenvectors): at n = 320, batch 819: 67.8 µs vs cuSOLVER's 203.0 µs per matrix (3.0×); at n = 448, batch 585: 2.1×. cuSOLVER wins at large n, and Auto routes there.
  • Batched SVD (gesvd vs cusolverDnXgesvdjBatched): at n = 8, batch 16384: 0.0064 vs 0.339 µs per matrix; at n = 32: 0.468 vs 0.768 µs.

These are single-machine numbers; see the Performance section of the README for full conditions and how to reproduce them.

Quick start

Build with a SYCL-capable compiler (DPC++ / Clang) using the CMake presets:

git clone https://github.com/jonasdelacour/BatchLAS.git
cd BatchLAS
cmake --preset dev
cmake --build --preset dev

Calling the C++ API — the backend comes from the queue, and options are structs with defaults:

#include <batchlas.hh>
using namespace batchlas;

Queue ctx(Device::default_device());          // backend resolved from the device
auto e = linalg::eigh(ctx, A.view());         // batched eigenvalues + eigenvectors
gemm(ctx, A.view(), B.view(), C.view(), {.alpha = 2.0f});
ctx.wait();                                   // results readable after this

Link from CMake with find_package(BatchLAS CONFIG REQUIRED) and target_link_libraries(my_app PRIVATE BatchLAS::batchlas). See the C++ API reference for the full conventions.
