# Error model (cause found 2026-10-30, in AdaptiveCpp): the default integrated multipass launches
# through clang's CUDA stub (include/AdaptiveCpp/hipSYCL/glue/generic/hiplike/clang.hpp:44-48,
# reached from hiplike_kernel_launcher.hpp:352-354; etc/AdaptiveCpp/acpp-core.json:22
# default-is-explicit-multipass false), which never reads cudaGetLastError. A failed launch runs

# wait throws; a 20-line acpp program without BatchLAS reproduces it. Explicit multipass would
